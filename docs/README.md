# VesperUI documentation

VesperUI is a pure-Python Windows GUI toolkit built on the Win32 API through
`ctypes`. It pairs native controls with owner-drawn Aurora widgets under a
single dark visual style.

## Guides

- [Getting started](getting-started.md) — installation, windows, layouts,
  callbacks, dialogs, menus, timers and headless testing.
- [Widget reference](widgets.md) — every widget, its constructor and its main
  methods.
- [Widget gallery](gallery.md) — one screenshot per widget class.
- [Styling and themes](styling.md) — `AURORA`, `make_style` and per-widget
  overrides.
- [Architecture](architecture.md) — module map, layout, painting, input and
  how to add a widget.
- [Releasing](releasing.md) — versioning, building, tags and PyPI publishing.
